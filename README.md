 Amazon Website Testing (Manual + Automation)

Project Name
Amazon Website Testing using Selenium

🌐 Website Name
Amazon India

 Website Link : https://www.amazon.in

📖 Project Description
This project focuses on testing the core functionalities of the Amazon website using both **Manual Testing** and **Automation Testing**.The main objective is to verify whether the website works correctly for end users by testing important features like search, product navigation, and login validation.

🛠️ Tools & Technologies Used
- Selenium WebDriver
- Java
- TestNG
- Maven
- Eclipse IDE

 Testing Types
- Manual Testing
- Automation Testing (Selenium)

📋 Test Scenarios Covered
- Homepage Load Verification  
- Search Functionality  
- Product Listing  
- Product Details Page  
- Navigation Menu  
- Login Validation  
- Footer Links  

🔄 Test Flow
1. Launch the browser  
2. Open Amazon website  
3. Verify homepage loads  
4. Perform product search (Laptop/Book)  
5. Verify product listing  
6. Click on product and verify details page  
7. Check navigation menu functionality  
8. Validate login without credentials  
9. Verify footer links  
10. Close the browser  

 🐞 Bug Report
- Login button validation issue observed  
- Error message handling needs improvement  

▶️ How to Run the Project
1. Import the project into Eclipse  
2. Ensure Maven dependencies are updated  
3. Open `AmazonTest.java`  
4. Right click → Run as → TestNG Test
